# NYC Street Parking: Street Cleaning Finder (61st to 185th St)

Find Manhattan block faces where street cleaning (Alternate Side Parking) **won't** hit
your car during a morning stay, sorted so the blocks closest to the toll line come first.

- **Southern limit is 61st St.** The congestion toll zone is "Manhattan south of *and including* 60th Street",
  so you're charged the moment you drive onto 60th.
- **Default focus: 61st to 110th St.** Pass `--max-street 185` for Harlem, Washington Heights, and Inwood.

## Usage (Python 3.10+, no dependencies)

```sh
python3 asp.py fetch                                   # refresh data from NYC Open Data (~20k signs)
python3 asp.py find                                    # today, 8:00 to 12:00, 61st to 110th St
python3 asp.py find --date 2026-10-16 --arrive 7:30 --leave 11:30 --town west
python3 asp.py find --max-street 185 --limit 100
```

Output columns: cross street #, block (street, from -> to), side of street, next cleaning, and
"swept earlier today" (cleaning already ended before you arrive).

## Files

| File | What |
|---|---|
| `asp.py` | `fetch` and `find` commands |
| `data/street_cleaning.csv` | Every street-cleaning schedule per block face, 61st to 185th St (generated by `fetch`) |
| `data/asp_suspensions_2026.csv` | Official 2026 ASP holiday suspensions ([NYC DOT](https://www.nyc.gov/html/dot/html/motorist/alternate-side-parking.shtml)). Add a new file each year. |
| `data/my_spots.csv` | Your own log: where you parked and how it went |

## Caveats

- This tool only covers street-cleaning signs. Meters, No Standing zones, hydrants, bus stops, and
  construction permits aren't included, so **always read the posted signs.**
- It doesn't know about emergency or weather suspensions. Check [@NYCASP](https://x.com/NYCASP) or 311.
- Source data: [Parking Regulation Locations and Signs](https://data.cityofnewyork.us/Transportation/Parking-Regulation-Locations-and-Signs/nfid-uabd).
  Re-run `fetch` every month or so.
